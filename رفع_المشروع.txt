═══════════════════════════════════════════════════════════════
          خطوات رفع المشروع على GitHub و Railway
═══════════════════════════════════════════════════════════════

📋 تم إعداد المشروع للرفع!

الملفات المضافة:
✅ Procfile - لـ Railway
✅ railway.json - إعدادات Railway
✅ .gitignore - محدث
✅ package.json - محدث مع Node.js version
✅ DEPLOY.md - دليل مفصل للنشر

═══════════════════════════════════════════════════════════════
الخطوة 1: رفع المشروع على GitHub
═══════════════════════════════════════════════════════════════

1. اذهب إلى GitHub وأنشئ مستودع جديد:
   https://github.com/new

2. افتح Terminal/PowerShell في مجلد المشروع

3. شغّل الأوامر التالية:

   git init
   git add .
   git commit -m "Initial commit: Discord DM Bot"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main

   (استبدل YOUR_USERNAME و YOUR_REPO باسمك ومستودعك)

═══════════════════════════════════════════════════════════════
الخطوة 2: النشر على Railway
═══════════════════════════════════════════════════════════════

1. اذهب إلى Railway:
   https://railway.app

2. سجّل الدخول باستخدام GitHub

3. اضغط على "New Project"

4. اختر "Deploy from GitHub repo"

5. اختر المستودع الذي رفعته

6. في Railway Dashboard:
   - اذهب إلى "Variables" أو "Environment"
   - أضف متغير جديد:
     Name: TOKEN
     Value: YOUR_BOT_TOKEN_HERE
     (ضع Token البوت هنا)

7. Railway سينشر المشروع تلقائياً!

═══════════════════════════════════════════════════════════════
⚠️ تحذيرات مهمة:
═══════════════════════════════════════════════════════════════

❌ لا ترفع ملف .env على GitHub!
✅ استخدم .env.example كقالب
✅ Token البوت يجب أن يكون في Railway Variables فقط
