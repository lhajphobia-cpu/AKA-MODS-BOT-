          الملفات التي يجب رفعها على GitHub
═══════════════════════════════════════════════════════════════

✅ الملفات التي يجب رفعها:

1. index.js              - ملف البوت الرئيسي
2. package.json          - معلومات المشروع والمكتبات
3. package-lock.json     - قفل إصدارات المكتبات
4. README.md             - دليل المشروع
5. DEPLOY.md             - دليل النشر
6. Procfile              - ملف لـ Railway
7. railway.json          - إعدادات Railway
8. .gitignore            - ملف لتجاهل الملفات الحساسة

═══════════════════════════════════════════════════════════════
❌ الملفات التي لا يجب رفعها (محظورة):

1. .env                  - يحتوي على Token سري
2. node_modules/         - مجلد المكتبات (كبير جداً)
3. *.log                 - ملفات السجلات
4. env.example.txt       - ملف قديم

═══════════════════════════════════════════════════════════════
📝 ملاحظات:

- ملف .gitignore سيتأكد تلقائياً من عدم رفع الملفات الحساسة
- عند استخدام git add . سيتم رفع الملفات الصحيحة فقط
- لا تقلق، .gitignore سيتعامل مع الملفات المحظورة

═══════════════════════════════════════════════════════════════
🚀 الأوامر للرفع:

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main

ملاحظة: git add . سيرفع الملفات الصحيحة فقط بفضل .gitignore
